ELECTRONOVA - STRICT HTML & CSS SYLLABUS WEBSITE

FILES
- index.html       : Homepage with four clickable categories
- mobiles.html     : Mobiles products only
- laptops.html     : Laptops products only
- audio.html       : Audio products only
- accessories.html : Accessories products only
- style.css        : One external CSS file shared by all pages

HOW NAVIGATION WORKS
Each category is a normal HTML hyperlink:
<a href="mobiles.html">Mobiles</a>

When the user clicks Mobiles, the browser opens mobiles.html.
The same method is used for laptops.html, audio.html and accessories.html.
All pages are part of one website and share the same navigation and stylesheet.

HOW TO RUN
1. Keep all HTML files and style.css in the same folder.
2. Double-click index.html to open the website in a browser.
3. Click any category to open its separate product page.

SYLLABUS APPROACH
- HTML: document structure, headings, paragraphs, links, images, lists,
  div/section/article elements, forms and input elements.
- CSS: external stylesheet, element/class selectors, colors, backgrounds,
  font and text properties, width, spacing, borders, box model, Flexbox,
  hover pseudo-class and responsive media queries.
- Not yet JavaScript, React, frameworks, database or backend are used.

NOTE
Product names, prices and descriptions are sample content.
The contact form is a front-end demonstration only; it does not send or store messages.
Product images are loaded from Unsplash, so an internet connection is needed for images.
